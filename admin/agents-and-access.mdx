---
title: "Company access"
description: "Give your team scoped access to company tools through their connected agents."
---

Connect your AI from **Agents**. Claude Code, Codex, Cursor, and other supported agents use your Passport connection and its permissions. Agents and subagents using the same connection share that access boundary; Passport does not require a separate identity for each one.

Use **Apps → Workspace** to connect company accounts. People request access from **Apps**, administrators review it in **Apps → Workspace**, and **Approvals** handles actions that require consent.

Company access requires Enterprise workspace controls and PostgreSQL. The GitHub organization connection supports repository details, issue lists, individual issues, issue creation, and issue comments.

## Connect an organization

1. Create a GitHub App and install it on the repositories you want Passport to govern. Give it the repository permissions needed for your selected actions: metadata read, and issues read or write.
2. In **Apps → Workspace → Company provider accounts**, enter the GitHub App ID and installation ID, then choose its private PEM file.
3. Preview the installation, select specific repositories, and create the connection.

Passport verifies the selected repository IDs and encrypts the private key. It requests short-lived installation tokens scoped to the particular repository and permissions needed for each invocation. The private key and provider tokens are never given to the agent.

## Request company access

Open the company account in **Apps** and request the actions and repositories you need, with a purpose and expiry. Administrators review these requests under **Apps → Workspace**. An approval cannot override an explicit block or an unavailable connection.

Your existing workspace connection exposes approved company tools alongside your personal tools. Each agent's app selection can narrow your access further.

## Approvals and activity

A grant can require approval for each action. Review the proposed action in **Approvals**. Passport checks the current permission and records the outcome. Open **Activity** for your work or **Audit** for workspace activity. The **Runs** view includes durable action receipts and their approval history.

Standalone managed identity setup has been retired. Existing audit records are retained. For scripts and CI using Passport CLI, see [Automation credentials](/admin/people-and-teams#automation-credentials).
