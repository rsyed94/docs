This guide gets you from invite to a working AI assistant in a few minutes. The same path works on Windows, Linux, and macOS. The macOS desktop app is optional — handy if you want to wire several local apps at once, not required.

## Accept your invite

Open the invite email and click the link. That signs you into your workspace.

Keep the link: any Passport link that includes your workspace works to sign in later (your invite link or your workspace page URL).

## 1. Connect an app

Open **Apps**, choose an app you use (for example GitHub), and select **Connect**.

- If your workspace allows it, Passport connects right away.
- If review or company setup is needed, Passport explains what is left.

When an app uses your own account, Passport opens the provider's sign-in page in your browser. You approve as yourself. Your AI assistant never sees a password or token — those stay in Passport.

## 2. Add an AI assistant

Open **AI Clients → Add client** and pick what you use:

- **ChatGPT or Claude.ai** — paste the connection URL Passport shows, then approve in the browser.
- **Cursor, VS Code, Claude Desktop, and similar** — use the one-click link or setup steps Passport shows, then finish in the browser.
- **Terminal tools (Claude Code, Codex, scripts)** — install [Passport CLI](/quickstart/cli), run `passport login`, and confirm in the browser.
- **Several local apps on macOS** — optionally use the desktop app to set them up together.

<Tabs>
  <Tab title="Windows">
    1. Open Passport in your browser and choose **Add client**.
    2. Follow the setup Passport shows for your AI app, or install Node.js 20\+ and Passport CLI.
    3. Finish browser sign-in, then ask your AI assistant to list the tools it can use.
  </Tab>
  <Tab title="Linux">
    1. Open Passport in your browser and choose **Add client**.
    2. Follow the setup Passport shows for your AI app, or install Node.js 20\+ and Passport CLI.
    3. Finish browser sign-in, then ask your AI assistant to list the tools it can use.
  </Tab>
  <Tab title="macOS">
    1. Use the same browser path as Windows and Linux.
    2. Optionally install Passport Desktop if you want to configure several local apps in one pass.
    3. Finish browser confirmation and check each client in the install hub.
  </Tab>
</Tabs>

### ChatGPT and Claude.ai

These run in the browser, so they connect with a **connection URL** instead of a local install. Passport shows and copies it under **AI Clients → Add client**. It looks like:

```text
https://<your-passport-host>/w/<your-workspace-id>/mcp
```

Your workspace id is the `ws_…` part of that path (and of your Passport browser URL).

<Tabs>
  <Tab title="ChatGPT">
    <Steps>
      <Step title="Open connector settings">
        Go to ChatGPT's Connectors settings and click Create. If you do not see Create, turn on Developer mode under Connectors → Advanced first.
      </Step>
      <Step title="Paste the URL">
        Paste the connection URL as the server URL and continue.
      </Step>
      <Step title="Allow">
        A Passport page opens. Click Allow. You approve as yourself; ChatGPT never sees a token or password.
      </Step>
    </Steps>
  </Tab>
  <Tab title="Claude.ai">
    <Steps>
      <Step title="Open connector settings">
        Go to Claude.ai's connector settings and click Add custom connector. Anthropic currently allows custom connectors on Free (one connector) as well as Pro, Max, Team, and Enterprise. If the button is missing, check the limit in your Claude account.
      </Step>
      <Step title="Paste the URL">
        Paste the connection URL as the server URL and continue.
      </Step>
      <Step title="Allow">
        A Passport page opens. Click Allow. You approve as yourself; Claude.ai never sees a token or password.
      </Step>
    </Steps>
  </Tab>
</Tabs>

### Optional: macOS desktop app

If you use several local apps (Claude Desktop, Claude Code, Cursor, VS Code, Codex), the desktop app can configure them in one pass. It needs macOS 11 or later.

<Steps>
  <Step title="Download and open">
    Download from your workspace's download page, drag Passport to Applications, then right-click and choose Open the first time.
  </Step>
  <Step title="Sign in">
    Paste any Passport link that includes your workspace. Confirm the short code in your browser and approve.
  </Step>
  <Step title="Connect local apps">
    Choose each AI app you want Passport to set up. Passport keeps a backup and will not overwrite a config it cannot understand.
  </Step>
</Steps>

<Warning>
  If you use both the Claude desktop connection and the Claude.ai connector, Claude may show each tool twice. Keep just one. See [Troubleshooting](/troubleshooting).
</Warning>

### Terminal and automation

For Claude Code, Codex CLI, scripts, and CI, use [Passport CLI](/quickstart/cli):

```sh
npm i -g passport-bridge
passport login --cloud https://passportmcp.com --workspace <workspace-id>
passport search "issues"
passport run github_search_issues '{"query":"SSO"}'
```

## 3. Check that everything works

Open **Home** (Getting started) or **AI Clients**. On the checklist step **Prove the governed path**, choose **Run setup check**.

Passport runs a safe, read-only test against your current workspace rules. It does not contact the app provider. When it succeeds, Passport opens **Activity** so you can see the result. If something changed (for example a client was disconnected), the step stays incomplete and you can try again.
